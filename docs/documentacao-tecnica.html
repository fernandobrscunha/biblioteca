Seção 1

Introdução e objetivos

A Biblioteca Virtual é uma aplicação web para gerenciamento de livros. A interface atual permite listar o acervo cadastrado e cadastrar novos títulos, persistindo-os em um banco de dados MySQL. As páginas são servidas de forma dinâmica pelo servidor (server-side rendering) usando o motor de templates EJS.

Os objetivos principais desta documentação são:

  • Descrever a arquitetura e o papel de cada módulo do sistema;
  • Documentar o modelo de dados e o ciclo de vida de uma requisição;
  • Servir de referência para manutenção e evolução do código.

Seção 2

Visão geral da arquitetura

O sistema segue o padrão cliente–servidor. O navegador faz requisições HTTP ao servidor Express, que processa a solicitação nas camadas de roteamento, controle e acesso a dados, e devolve páginas HTML renderizadas no servidor. As folhas de estilo e os ícones são fornecidos pela CDN jsDelivr (Bootstrap 5.3.8 e Bootstrap Icons), sem arquivos CSS locais.

O fluxo completo de uma requisição típica: o navegador chama uma rota registrada em web.js; o controlador orquestra a operação; o modelo Book executa a consulta/gravação via Knex (query builder) no MySQL; por fim, o controlador devolve a resposta (renderização de um template EJS ou mensagem de status).

Seção 4

Estrutura de diretórios

Organização do repositório no padrão MVC:

biblioteca/
├── index.js                      # Ponto de entrada · configuração do Express e do EJS
├── package.json                  # Metadados e dependências do projeto
├── readme.md                     # Documentação de uso, instalação e configuração
|
└── src/
    ├── config/
    │   └── db.js                 # Conexão com o MySQL (Knex)
    ├── controllers/
    │   └── BookController.js     # index() → lista livros · store() → cadastra livro
    ├── models/
    │   └── Book.js               # all() → SELECT · save() → INSERT
    ├── routes/
    │   └── web.js                # Registro das rotas HTTP
    └── views/
        ├── components/
        │   └── card_book.ejs     # Card individual de livro (dentro da grade)
        └── pages/
            ├── home.ejs          # Tela inicial · acervo e seções institucionais
            └── book_form.ejs     # Formulário de cadastro de livro
Boas práticas observadas: a separação em rotas → controlador → modelo → visão mantém as responsabilidades isoladas; o template de card é um componente reutilizável (card_book.ejs) incluído pela página inicial.

Seção 6

Modelo de dados (banco de dados)

O banco contém uma única tabela, books. A coluna cover guarda a URL da imagem de capa (atribuída automaticamente pelo controlador durante o cadastro).

DDL de referência

CREATE DATABASE biblioteca;
USE biblioteca;

CREATE TABLE books (
    ID    BIGINT UNSIGNED AUTO_INCREMENT,
    title VARCHAR(100)  NOT NULL,
    author VARCHAR(100) NOT NULL,
    resume TEXT          NOT NULL,
    cover VARCHAR(255)   NULL,
    PRIMARY KEY(ID)
);
Atenção: o comando acima considera a coluna cover. Se a base existente foi criada apenas com o readme.md (sem cover), adicione-a com ALTER TABLE books ADD COLUMN cover VARCHAR(255) NULL; para que o cadastro não falhe.

Decisões de interface

  • Bootstrap 5.3.8 como design system, consumido via CDN;
  • Tema flat e minimalista, em tons pastéis (verde + bege), transmitindo confiança sem peso visual;
  • Tipografia grande (display-*), cantos arredondados (rounded-*), sombras suaves (shadow-sm) e botões pill (rounded-pill);
  • Grade responsiva: cards adaptam-se de 4 colunas (desktop) a 1 coluna (celular).

Seção 11

Como executar o projeto

  1. Instalar as dependências: npm install
  2. Garantir o MySQL em execução e o banco biblioteca criado (ver Seção 6);
  3. Conferir as credenciais em src/config/db.js;
  4. Iniciar o servidor: node index.js
  5. Acessar http://localhost:3000.
node index.js
# Rodando em: http://localhost:3000
